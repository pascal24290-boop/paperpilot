# PaperPilot V1
Prototype mobile-first, sans backend, pour tester l'expérience PaperPilot.
Fonctions : ajout de fichier (démo), analyse simulée, résultat, lecture vocale, sauvegarde locale, rappels et réglages d'accessibilité.
Important : cette V1 ne transmet aucun document à une IA et ne doit pas être utilisée avec de vrais documents sensibles. L'analyse est une démonstration.
